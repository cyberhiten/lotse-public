LOTSE — A deterministic security-signal dashboard

LOTSE aggregates vulnerability and threat intelligence — CISA KEV, EPSS, Exploit-DB, CERT-Bund — into a single, reproducible dashboard. Every module is a fetch-and-score step running on a plain Linux cron: no AI, no trackers, no ambiguity. What you see is what the rules evaluated, byte-for-byte the same on every machine.
